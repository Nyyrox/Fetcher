HTTP utility API

Fetch. Inspect. Proxy.

Fetcher is a lightweight HTTP utility Worker for authorized requests, HTML inspection, player-page inspection, JavaScript analysis and media proxying. The API returns structured JSON where appropriate and keeps the interface intentionally simple.

Routes

All endpoints are relative to this Worker.

GET Fetch

Fetch an HTTP(S) resource and return its response details.

/fetch?url=<url>
GET Proxy

Proxy a resource while forwarding useful request headers and range requests.

/proxy?url=<url>&referer=<url>&origin=<url>
GET Inspect

Inspect HTML for scripts, iframes, links, API candidates and media references.

/inspect?url=<html-url>
GET Inspect Player

Inspect a player page and linked player JavaScript without executing it.

/inspect-player?url=<player-url>
GET Inline JS

Extract inline script blocks and useful request/session/source clues.

/extract-inline-js?url=<html-url>
GET Inspect Script

Fetch a JavaScript asset and identify API, stream, session and media references.

/inspect-script?url=<js-url>
GET Extract Links

Extract scripts, iframes, hrefs and other useful page links.

/extract-links?url=<html-url>
GET Health

Check that the deployment is responding.

/health
GET / POST Resolve

Resolve anime metadata against the configured Anikoto source.

/resolve?title=<name>&episode=<number>
GET Search

Search the configured anime source directly.

/search?keyword=<title>

Inspection

Static analysis, not a browser runtime.

The Worker can fetch HTML and JavaScript assets and inspect their text. It does not execute page JavaScript, so requests generated only after browser execution may not appear in static inspection results.

Examples

Replace the placeholders with URL-encoded values.

# Inspect a player page https://fetcher.ammhfoo.workers.dev/inspect-player?url=<ENCODED_PLAYER_URL> # Inspect a JavaScript asset https://fetcher.ammhfoo.workers.dev/inspect-script?url=<ENCODED_JS_URL> # Extract inline JavaScript https://fetcher.ammhfoo.workers.dev/extract-inline-js?url=<ENCODED_HTML_URL> # Fetch with upstream browser-context headers https://fetcher.ammhfoo.workers.dev/fetch?url=<URL>&referer=<REFERER>&origin=<ORIGIN> # Search anime https://fetcher.ammhfoo.workers.dev/search?keyword=Naruto # Resolve anime metadata + episode https://fetcher.ammhfoo.workers.dev/resolve?title=Naruto&episode=53

Notes

Keep usage authorized.

Only use Fetcher with resources you are authorized to access. Local targets are blocked. Fetcher does not bypass DRM, CAPTCHA or access controls. A 403 from an upstream service is still an upstream 403; adding headers can only reproduce an allowed browser request, not grant permission.
