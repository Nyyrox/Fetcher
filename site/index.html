FETCHER
Universal HTTP / CDN inspector
API documentation

Fetch it. Inspect it. Understand it.

A lightweight Cloudflare Worker for authorized HTTP requests, HTML inspection, player/source inspection, JavaScript asset analysis, and media proxying. Browser JavaScript is inspected statically; it is not executed by the Worker.

Fetch

Fetch a public HTTP(S) resource and return its response through the Worker.

GET/fetch?url=<url>

Proxy

Stream a resource through the Worker. Useful for media/CDN testing and range requests.

GET/proxy?url=<url>&referer=<url>&origin=<url>

Inspect HTML

Extract scripts, iframes, links, API candidates, media candidates and linked JavaScript clues.

GET/inspect?url=<html-url>

Inspect Player

Inspect an embedded player page and linked player scripts without executing them.

GET/inspect-player?url=<player-url>

Inline JavaScript

Extract inline script blocks and return useful matches such as fetch, XHR, session and source references.

GET/extract-inline-js?url=<html-url>

Inspect Script

Fetch a JavaScript asset and identify API, stream, session and media references.

GET/inspect-script?url=<js-url>

Extract Links

Return scripts, iframes, hrefs, links and inline-script summaries from an HTML page.

GET/extract-links?url=<html-url>

Health

Simple deployment/version check.

GET/health

Request headers

ParameterPurpose
refererSets the upstream Referer header.
originSets the upstream Origin header.
header_*Passes a specific additional header, e.g. header_Accept=application/json.
RangeForwarded from the incoming request for media/range testing.

Examples

# Inspect a player https://fetcher.ammhfoo.workers.dev/inspect-player?url=<ENCODED_PLAYER_URL> # Extract inline scripts https://fetcher.ammhfoo.workers.dev/extract-inline-js?url=<ENCODED_HTML_URL> # Inspect a JS asset https://fetcher.ammhfoo.workers.dev/inspect-script?url=<ENCODED_JS_URL> # Fetch with browser context headers https://fetcher.ammhfoo.workers.dev/fetch?url=<URL>&referer=<REFERER>&origin=<ORIGIN>
Use these routes only with resources you are authorized to access. The Worker blocks local targets and does not execute page JavaScript, bypass DRM/CAPTCHA, or defeat access controls. Runtime requests made by a real browser still need to be observed with a browser/network tool.
